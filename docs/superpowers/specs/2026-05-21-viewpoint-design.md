# ViewPoint - 三维战场信息可视化软件 设计文档

## 1. 项目概述

基于 Proto 协议解析，开发 Windows 平台三维战场信息可视化软件。核心聚焦车辆实体展示、战场态势可视化、实时动态监控。场景采用极简暗色背景，轻量化呈现核心作战数据与实体状态，支持自由三维观测与快速信息查询。

## 2. 技术方案

| 项目 | 选型 |
|------|------|
| 桌面框架 | Electron 28+ |
| 三维渲染 | Three.js |
| Proto 编解码 | protobufjs |
| UI | HTML/CSS/原生 JS |
| 通信协议 | UDP (Node.js dgram) |

选择 Electron + Three.js 方案：UDP 通过 Node.js 原生支持，Three.js 三维生态成熟，开发迭代快。

## 4. 模块设计

### 4.1 数据解析与网络层

**Proto 消息优先级：** net_frame.proto > net_info.proto > net.proto

**核心消息类型：**

| 消息 | 来源 | 用途 |
|------|------|------|
| NetMessage | net_frame | 通用消息包裹（所有数据入口） |
| MsgCombineSend | net_frame | 批量 tick 数据 |
| UploadCarInfo | net | 车辆实时状态 |
| UploadRadar | net | 雷达点云数据 |
| UploadUAVInfo | net | 无人机状态 |
| req_Login | net_frame | 登录消息（发送用） |

**UDP 通信流程：**
1. 启动 → 创建 UDP socket (dgram.createSocket)
2. 发送 req_Login(account="root", password=房间号)
3. 循环接收 UDP 包：
   - 解包 NetMessage
   - 根据 msg.type_url 判断消息类型
   - 反序列化具体消息体
   - 更新 DataStore
   - 通过 IPC 推送到渲染进程

**坐标转换：** 原始单位厘米 → 米（÷100） → 偏移到场景中心

### 4.2 三维场景与视角控制

**场景配置：**
- 纯黑背景，无地形无建筑
- 三维坐标轴参考线（X红/Y绿/Z蓝）
- 网格地面辅助线（可选开关）
- 环境光 + 方向光

**相机控制：**

| 操作 | 行为 |
|------|------|
| 左键拖拽 | 环绕旋转（OrbitControls） |
| 滚轮 | 缩放 |
| 右键拖拽 | 平移 |
| R 键 | 复位到战场中心 |

### 4.3 车辆实体管理

**车辆几何体：**

| 车辆类型 | 几何体 | 尺寸参考 |
|----------|--------|----------|
| F1 | 长方体（车体）+ 圆柱（炮塔） | 较小 |
| 99A | 较大长方体（车体）+ 圆柱（炮塔） | 较大 |
| UAV | 小型四旋翼几何体 | 小型 |

**颜色方案：** 蓝方=蓝色系，红方=红色系。通过颜色深浅区分不同类型。

**车辆标识：** 每辆车上方显示 ID 文字标签（CSS2DRenderer），蓝方蓝字、红方红字。

### 4.4 战场态势可视化

| 范围类型 | 渲染方式 | 颜色 |
|----------|----------|------|
| 侦察范围 | 半透明球体 | 青色半透明 |
| 攻击范围 | 半透明球体/扇形 | 红色半透明 |
| 雷达范围 | 环形扫描线 + 半透明圆盘 | 绿色半透明 |
| 摄像头范围 | 视锥体线框 | 黄色线框 |

**动态效果：**
- 车辆运动轨迹（尾迹线）
- 雷达扫描动画（旋转扇形）

**左侧面板：**
- 车辆列表按阵营分组（蓝色/红色）
- 每项显示：类型 + 编号 + 阵营色标
- 点击 → 相机自动聚焦到该车辆
- 筛选：按 ID 搜索、按类型筛选（F1/99A/UAV）

**右侧面板：**
- 选中车辆后显示详细信息
- 基本信息：ID、类型、阵营、操控方式
- 状态数据：位置、速度、朝向、加速度
- 损伤信息：底盘/炮塔/左履带/右履带（百分比进度条）
- 弹药信息：各弹种数量、当前弹种
- 态势范围开关：侦察/攻击/雷达/摄像头范围的显示开关

**顶部工具栏：**
- 视角复位按钮
- 场景重置按钮
- 连接状态指示灯
- 房间号显示

```json
{
  "server": {

    "port": 20003
  },
  "room": {
    "id": 1
  },
  "login": {
    "account": "root",
    "password": "1"

    "showGrid": true,
    "showAxis": true,
```

## 7. 数据更新频率

- UDP 数据接收：实时（服务器推送频率）
- Three.js 渲染：60fps (requestAnimationFrame)
- UI 面板刷新：每帧同步或节流至 10fps

## 8. 关键约束

- Proto 文件优先级：net_frame.proto > net_info.proto > net.proto
- 坐标单位：原始厘米，内部转换为米
- 阵营编码：10/1=蓝色，20/2=红色
- 车辆类型：F1Create、A99Create、UAV_1~4
- 文字统一使用中文
