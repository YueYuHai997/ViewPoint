# ViewPoint 界面皮肤「苍穹」— 集成说明

把视觉层换成冷峻青蓝的切角 HUD 风格。**业务逻辑零改动**,只替换一个 CSS 文件 + 给两三个文件打很小的补丁。

---

## 1. 替换样式(必做,占 90% 效果)

用 `交付/styles.css` 覆盖 `renderer/styles.css`。

下面这些**全部是纯 CSS,无需改任何 JS** 就能生效:

- 工具栏切角按钮、选中态高亮、标题发光 + 英文副标题(`TACTICAL VIEW SYSTEM` 由 `::after` 生成)
- 连接状态徽章的**雷达呼吸动画**(`.status-dot.connected`,断开时不呼吸)
- HUD 浮窗的切角造型 + 跟随切角的青蓝发光内描边 + 标题竖条/装饰线
- 车辆列表菱形阵营标记、选中左条、悬停高亮
- 车辆信息分组标题的发光竖条
- **损伤条 → 分段式能量格**(在原 `.damage-bar` 上叠加等距间隙 + 倾斜,颜色仍由 `RightPanel.renderDamageBar` 的内联 `background` 控制)
- 态势范围滑块、日志面板、罗盘(青蓝化 + 扫描扇形)、滚动条、3D 场景上的扫描线 + 暗角

> 字体:已使用 `Consolas/monospace` 系统字体栈,**不引任何外部字体**,离线 Electron 正常显示。
> 若机器上装有 `Rajdhani`/`Share Tech Mono` 会自动优先用,没有也不影响。

## 2. 顶栏「数字时钟 + 任务计时」(需要新增元素)

这两个元素原本不存在,在 `ui/Toolbar.js` 的 `render()` 里,把 `.toolbar-right` 末尾补上一个容器,并加一个每秒走的定时器。

### 2.1 `Toolbar.js` —— 在 `render()` 的模板里,`#fps-display` 后面加:

```html
<div class="tb-clock-wrap">
  <span id="sys-clock">--:--:--</span>
  <span id="mission-timer">任务 T+00:00:00</span>
</div>
```

### 2.2 `Toolbar.js` —— 在 `render()` 末尾(绑定事件之后)启动时钟:

```js
this._missionStart = Date.now();
this._startClock();
```

### 2.3 `Toolbar.js` —— 在类里新增两个方法:

```js
_startClock() {
  const pad = (n) => String(n).padStart(2, '0');
  const tick = () => {
    const now = new Date();
    const clockEl = this.container.querySelector('#sys-clock');
    const missEl  = this.container.querySelector('#mission-timer');
    if (clockEl) {
      clockEl.textContent = `${pad(now.getHours())}:${pad(now.getMinutes())}:${pad(now.getSeconds())}`;
    }
    if (missEl) {
      const s = Math.floor((Date.now() - this._missionStart) / 1000);
      missEl.textContent = `任务 T+${pad(Math.floor(s / 3600))}:${pad(Math.floor((s % 3600) / 60))}:${pad(s % 60)}`;
    }
  };
  tick();
  this._clockTimer = setInterval(tick, 1000);
}

_stopClock() {
  if (this._clockTimer) clearInterval(this._clockTimer);
}
```

（任务计时这里从「软件启动」起算;如果你有真正的对局开始时间,把 `this._missionStart` 换成那个时间戳即可。）

## 3. 让「车辆列表 / 车辆信息」纵向铺满整个界面

面板是可拖拽浮窗,默认位置/大小由各自的 `defaultRect` 决定。改成铺满:

### `hud/panels/LeftPanel.js` 构造函数里:

```js
super('left', '车辆列表', {
  defaultRect: { x: 12, y: 52, w: 264, h: window.innerHeight - 92 },
  minSize: { w: 220, h: 240 },
  closable: true, minimizable: true, resizable: true
});
```

### `hud/panels/RightPanel.js` 构造函数里:

```js
super('right', '车辆信息', {
  defaultRect: { x: window.innerWidth - 312, y: 52, w: 300, h: window.innerHeight - 92 },
  minSize: { w: 260, h: 280 },
  closable: true, minimizable: true, resizable: true
});
```

> ⚠️ `PanelManager` 会把用户拖动后的位置存到本地。改完 `defaultRect` 后如果面板没回到新位置,是读了旧的本地缓存——清一次缓存(或换 storage key)即可恢复默认全高。

## 4. (可选)底部状态栏右侧的「SYS NOMINAL」呼吸灯

CSS 已经写好 `.sys-nominal` 样式(带呼吸绿点)。若想要,在 `index.html` 的 `#status-bar` 里加一个:

```html
<span class="sys-nominal">SYS NOMINAL</span>
```

不加也不影响其它部分。

## 改动清单速览

| 文件 | 改动 | 是否必须 |
|---|---|---|
| `renderer/styles.css` | 整体替换 | ✅ 必须 |
| `ui/Toolbar.js` | 加时钟元素 + 定时器(3 处) | 想要顶栏时钟才做 |
| `hud/panels/LeftPanel.js` | 改 `defaultRect` 为全高 | 想要铺满才做 |
| `hud/panels/RightPanel.js` | 改 `defaultRect` 为全高 | 想要铺满才做 |
| `index.html` | 加 `.sys-nominal` 一行 | 可选 |

只做第 1 步就能拿到 90% 的科技化效果;2/3 步是你点名要的时钟和铺满面板。
